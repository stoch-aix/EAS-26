1. Derivation of Conditional Density f(x|y)

By definition, the conditional probability density is computed by taking the joint density function and dividing it by the marginal density of the conditioning variable:

f(x|y) = fX,Y(x, y) / fY(y)

The joint distribution exponent for a standard bivariate normal distribution with correlation coefficient ρ is expanded inside the exponent matrix as:

-1 / [2(1-ρ²)] · [x² - 2ρxy + y²]

To isolate the terms involving x, we algebraically complete the square inside the exponent brackets with respect to the variable x:

x² - 2ρxy + y² = (x - ρy)² + y²(1 - ρ²)

When substituting this back into the exponential expression, the term containing only y splits off into a separate exponential factor:

exp(- (x - ρy)² / [2(1-ρ²)]) · exp(- y² / 2)

The second factor exp(-y²/2) matches the shape of the marginal distribution fY(y) exactly and is completely canceled out by the denominator. This leaves behind a single Gaussian distribution pattern for X:

f(x|y) = 1 / [√(2π(1-ρ²))] · exp(- (x - ρy)² / [2(1-ρ²)])

This explicitly proves that given Y=y, the distribution of X is normally distributed with a shifted mean of μX|Y = ρy and a shrunken variance of σ²X|Y = 1 - ρ².

2. Integration Steps to find E[X|Y=y]

Using the freshly derived conditional density distribution f(x|y), we can evaluate the integration step to calculate the expected value:

E[X | Y=y] = ∫-∞∞ x · f(x|y) dx

We make a clean substitution by setting u = (x - ρy) / √(1-ρ²), meaning dx = √(1-ρ²) du and x = ρy + √(1-ρ²)u:

= ∫-∞∞ (ρy + √(1-ρ²)u) · [1/√(2π) e-u²/2] du

Distributing this expression splits the structure into two individual integral parts:

= (ρy) ∫-∞∞ [PDF(u)] du + √(1-ρ²) ∫-∞∞ u · [PDF(u)] du
  • The left integral sums up to 1 because integrating a standard normal PDF over all real numbers equals 1.
  • The right integral evaluates to 0 because u · e-u²/2 is an asymmetrical odd function balanced across zero.

This cancels out the entire second term, showing that the continuous definition integral simplifies perfectly to the formula running our live visualization chart: E[X | Y=y] = ρy.
