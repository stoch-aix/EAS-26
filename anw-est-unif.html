Erwartungstreue Schätzfunktionen im Modell $X_i \sim U(0,\vartheta)$

mit Anwendung auf Circuit-Breaks in verteilten Software-Systemen

1. Anwendungskontext in der Informatik

In modernen, verteilten Cloud-Architekturen (wie Kubernetes-Clustern) ist die präzise Steuerung von System-Timeouts und Lastgrenzen wichtig. Nehmen wir an, ein Service-Task verarbeitet eingehende Anfragen, deren Verarbeitungszeit stark schwankt. Durch eine gleichmäßigen Datenaufteilung sei bekannt, dass die Antwortzeiten $X_1, X_2, \dots, X_n$ unabhängig und identisch verteilt (i.i.d.) gemessen werden nach einer stetigen Gleichverteilung:

$$X_i \sim U(0, \vartheta)$$

Hierbei repräsentiert der Parameter $\vartheta$ (Theta) die maximale, theoretische Verarbeitungszeit des Endpunkts. Das DevOps-Monitoring-System erfasst nun eine Stichprobe von $n$ aufeinanderfolgenden Anfragen. Das Ziel ist es, aus dieser Stichprobe den wahren Wert von $\vartheta$ zu schätzen, um eine Sicherung (Circuit Breaker) optimal zu konfigurieren. Durch die Sicherung wird (zeitweise) eine überlastete Ressource (etwa eine Datenbank) abgeschaltet. Der User bekommt gleich eine negative Antwort und muss nicht bis zum Timeout warten. Hierdurch wird auch vermieden, dass der Thread-Pool für wartende Anfragen überläuft und der Service ebenfalls ausfällt.

2. Mathematische Herleitung des Schätzers

Die vollständige Dichtefunktion $f(x)$ und die vollständige Verteilungsfunktion $F(x)$ einer einzelnen Zufallsvariablen $X_i \sim U(0, \vartheta)$ lauten per Fallunterscheidung:

$$f(x) = \begin{cases} \frac{1}{\vartheta} & \text{für } 0 \le x \le \vartheta \\ 0 & \text{sonst} \end{cases} \quad \text{und} \quad F(x) = \begin{cases} 0 & \text{für } x < 0 \\ \frac{x}{\vartheta} & \text{für } 0 \le x \le \vartheta \\ 1 & \text{für } x > \vartheta \end{cases}$$

Der Maximum-Likelihood-Schätzer ($M$)

Da alle beobachteten Werte $X_i \le \vartheta$ sein müssen, ist der intuitive Maximum-Likelihood-Schätzer (MLE) das Maximum der Stichprobe: $$M = \max(X_1, X_2, \dots, X_n) = X_{(n)}$$ Um zu prüfen, ob $M$ erwartungstreu ist, bestimmen wir seinen Erwartungswert $E[M]$. Dazu leiten wir die vollständige Verteilungsfunktion $F_M(x) = P(M \le x)$ her. Unter Verwendung formal korrekter Ereignismengen ergibt sich für den Bereich $0 \le x \le \vartheta$:

$$F_M(x) = P(M \le x) = P(\{X_1 \le x\} \cap \dots \cap \{X_n \le x\}) = \prod_{i=1}^n P(\{X_i \le x\}) = [F(x)]^n = \left(\frac{x}{\vartheta}\right)^n$$

Die vollständige Verteilungsfunktion $F_M(x)$ für das Maximum lautet somit per Fallunterscheidung:

$$F_M(x) = \begin{cases} 0 & \text{für } x < 0 \\ \left(\frac{x}{\vartheta}\right)^n & \text{für } 0 \le x \le \vartheta \\ 1 & \text{für } x > \vartheta \end{cases}$$

Durch Ableiten der Verteilungsfunktion nach $x$ erhalten wir die vollständige Wahrscheinlichkeitsdichte $f_M(x)$:

$$f_M(x) = \begin{cases} \frac{n \cdot x^{n-1}}{\vartheta^n} & \text{für } 0 \le x \le \vartheta \\ 0 & \text{sonst} \end{cases}$$

Nun berechnen wir den Erwartungswert $E[M]$ über den einzig relevanten Bereich $[0, \vartheta]$:

$$E[M] = \int_{-\infty}^{\infty} x \cdot f_M(x) \, dx = \int_0^\vartheta x \cdot \frac{n \cdot x^{n-1}}{\vartheta^n} \, dx = \frac{n}{\vartheta^n} \int_0^\vartheta x^n \, dx = \frac{n}{\vartheta^n} \left[ \frac{x^{n+1}}{n+1} \right]_0^\vartheta = \frac{n}{n+1} \vartheta$$
Erkenntnis: Da $E[M] = \frac{n}{n+1} \vartheta \neq \vartheta$, ist der Schätzer $M$ nicht erwartungstreu (verzerrt). Er unterschätzt $\vartheta$ im Mittel systematisch. Da die Dichte für alle $x > \vartheta$ exakt $0$ ist, kann das Maximum den wahren Wert niemals überschreiten.

Konstruktion des erwartungstreuen Schätzers ($\hat{\vartheta}$)

Durch Skalierung mit dem Kehrwert des Verzerrungsfaktors eliminieren wir den Bias und erhalten die erwartungstreue Schätzfunktion $\hat{\vartheta}$:

$$\hat{\vartheta} = \frac{n+1}{n} M = \frac{n+1}{n} \max(X_1, X_2, \dots, X_n)$$

Beweis der Erwartungstreue: $$E[\hat{\vartheta}] = E\left[\frac{n+1}{n} M\right] = \frac{n+1}{n} E[M] = \frac{n+1}{n} \cdot \frac{n}{n+1} \vartheta = \vartheta$$
