Binomial Likelihood & MLE

This tool visualizes the Likelihood function for a Binomial experiment given the number of trials \(n\) and observed successes \(y\). It automatically computes and highlights the Maximum Likelihood Estimate (MLE) \(\hat{p}\).

Mathematical Derivation

1. The Probability Mass Function (Density)

For a fixed success probability \(p\), the probability of observing exactly \(y\) successes in \(n\) independent trials follows the Binomial distribution:

\[P(Y = y \mid p) = \binom{n}{y} p^y (1-p)^{n-y}\]

This can be conceptually built as a product of individual Bernoullxi trials. Let \(x_i \in \{0, 1\}\) represent the realisations of the i.i.d. random variables \( X_i \), \( i = 1, \ldots, n \). The density of \( X_i \) is \( f(x \mid p ) = p^x (1-p)^{1-x}, x \in \{ 0,1 \} \), and \( f(x \mid p ) = 0, x \in \mathbb{R}\backslash \{ 0,1 \} \). The density evaluated at \( x_i \) is \(f(x_i \mid p) = p^{x_i}(1-p)^{1-x_i}\), where \( x_i \in \{ 0, 1 \}, i = 1, \ldots, n \). Assuming independence, the joint density of the sequence evaluated at the realisations \( x_1, \ldots, x_n \) is the product:

\[\prod_{i=1}^n f(x_i \mid p) = \prod_{i=1}^n p^{x_i}(1-p)^{1-x_i} = p^{\sum_{i=1}^n x_i} (1-p)^{n - \sum_{i=1}^n x_i} = p^y (1-p)^{n-y}\] where \( y = \sum_{i=1}^n x_i \) is the observed number of successes.

Accounting for all \(\binom{n}{y}\) possible orderings of these outcomes yields the Binomial density above.

2. The Likelihood Function

In parameter estimation, the data (\(y, n\)) are fixed, and we vary the parameter \(p\). The likelihood function \(L(p \mid y)\) is structurally identical to the probability density but viewed as a function of \(p\):

\[L(p \mid y) = \binom{n}{y} p^y (1-p)^{n-y}\]

3. Derivation of the Maximum Likelihood Estimate (MLE)

To find the value of \(p\) that maximizes \(L(p \mid y)\), it is mathematically easier to maximize the natural logarithm of the likelihood function, called the Log-Likelihood \(\ell(p)\):

\[\ell(p) = \ln L(p \mid y) = \ln \binom{n}{y} + y \ln(p) + (n-y) \ln(1-p)\]

To find the maximum, we take the first derivative with respect to \(p\) and set it to zero: The ML estimator \( \hat p \) satisfies

\[\frac{d\ell(p)}{dp} \mid_{p=\hat p} = \frac{y}{\hat p} - \frac{n-y}{1-\hat p} = 0\]

Solving for \(\hat p\):

\[\frac{y}{\hat p} = \frac{n-y}{1-\hat p}\] \[y(1-\hat p) = \hat p(n-y)\] \[y - y\hat p = n\hat p - y \hat p\] \[y = n\hat p \implies \hat{p} = \frac{y}{n}\]

Thus, the Maximum Likelihood Estimate \(\hat{p}\) is simply the observed sample proportion, which is explicitly highlighted in the chart above.
